# Video as code demo

This is a deterministic, browser-based presentation of the verified harness
run. It is intentionally not a fake CI dashboard: the visible requirement
names, worktrees, commands, and commit IDs come from the local demo run.

Open `index.html` in a browser and record the 31-second loop with OBS, Clipchamp,
or the Windows screen recorder. Use the `Pause`, `Play`, and `Restart` controls
to capture a clean take.

Suggested narration:

> OpenSpec defines the contract. The Judge proves the test is red before code
> exists. The Author implements in an isolated worktree. The Referee runs the
> test again. Three requirements, three commits, zero failures.
